# robot-rumble

A prototype game project teaching children with diabetes how to manage their condition.

## Repository Layout

- `diagame/`: Active Godot 4 port (current gameplay work)
- `RobotRumble.gmx/`: Original GameMaker Studio 1.x project
- `UE3/`: Legacy Unreal Engine 3 experiment notes/scripts

## Godot Port Documentation

- `diagame/README.md`: Current status, structure, and troubleshooting notes
- `diagame/PORTING_REFERENCE.md`: GameMaker-to-Godot conversion patterns
- `diagame/CREDITS_ROOM_REFERENCE.md`: Credits room implementation details
- `diagame/TROUBLESHOOTING.md`: Symptom-to-fix index for common parser/export issues
